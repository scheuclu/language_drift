# Language Drift — web

Interactive visualization of per-year Word2Vec embeddings trained on
Common Crawl 2013–2025.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind v4 · Framer Motion · D3.

## Routes

- `/` — scrollytelling landing (`mask`, 2013→2025) + more-stories grid
- `/explore` — constellation explorer with search + scroll-driven year scrubbing. Accepts `?w=word` deep links.
- `/gallery` — top drifters with frequency-tier filter

## Data

Precomputed JSON shards under `public/data/`, generated by
`../scripts/precompute_web_data.py`:

- `manifest.json` — search index of all 19,663 eligible words
- `drift_gallery.json` — pre-sorted top 2,000 by total drift
- `words/<word>.json` — per-word: freq-by-year, drift-from-2013, top-25 neighbors per year

Total: ~156 MB across 19,664 files.

## Development

```bash
cd web
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Deploy to Vercel

This is a fully static site (every route prerenders). Recommended setup:

1. Push the repo (the parent repo containing `web/`) to GitHub.
2. On vercel.com, "Add new project" → import the repo.
3. Set **Root Directory** to `web`. Framework auto-detected as Next.js.
4. Build command: `npm run build`. Output: `.next` (default).
5. Deploy.

`/data/*` is cached `public, max-age=31536000, immutable` via
`next.config.ts` so the JSON shards hit Vercel's edge CDN.

### Or via CLI

```bash
cd web
npx vercel       # first run links the project
npx vercel --prod
```
