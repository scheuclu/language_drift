# Language Drift — web

Interactive visualization of per-year Word2Vec embeddings (TWEC/compass) trained
on Common Crawl 2014–2025. Data is served from Vercel Blob.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind v4 · Framer Motion · D3.

## Routes

- `/` — scrollytelling landing (`distancing`, 2014→2025) + more-stories grid
- `/explore` — constellation explorer with search + scroll-driven year scrubbing. Accepts `?w=word` deep links.
- `/ternary` — three-pole barycentric projection (default `crypto` vs encryption/scam/money)
- `/arith` — vector arithmetic over the latest-year embeddings
- `/space` — joint 2D UMAP cloud, animated across years
- `/gallery` — top drifters with frequency-tier filter

## Data

Hosted on **Vercel Blob** (not in git), under a versioned path (`data/v3/`); the
base URL lives in `lib/data-source.ts` (overridable via `NEXT_PUBLIC_DATA_BASE`).
Generated by `../scripts/precompute_*.py`, packed by `../scripts/pack_web_data.py`:

- `manifest.json` — search index of all ~19,595 eligible words
- `drift_gallery.json` — pre-sorted top 2,000 by total drift
- `space_index.json` — word → row index (also the row order of `vecs.bin`)
- `vecs.bin` — all per-word 12×300 float32 vectors, fixed 14,400-byte stride; the
  client HTTP-Range-fetches a single word's slice (`lib/vectors.ts`)
- `neighbors.bin` + `neighbors_index.json` — per-word neighbor shards packed into
  one file + a `{word: [offset, len]}` index, range-fetched (`lib/data.ts`)
- `arith.bin`, `space.bin` — whole-file loads for `/arith` and `/space`

~410 MB total, served from Blob's CDN; nothing data-related is committed. To
update after a retrain: re-run precompute + `pack_web_data.py`, upload to a new
`data/vN/`, and bump the version in `lib/data-source.ts`.

## Development

```bash
cd web
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Deploy to Vercel

This is a fully static site (every route prerenders). Recommended setup:

1. Push the repo (the parent repo containing `web/`) to GitHub.
2. On vercel.com, "Add new project" → import the repo.
3. Set **Root Directory** to `web`. Framework auto-detected as Next.js.
4. Build command: `npm run build`. Output: `.next` (default).
5. Deploy.

Data is on Vercel Blob (immutable per `data/vN/` version), not served from
`/public` — so there are no `/data` cache rules in `next.config.ts`.

### Or via CLI

```bash
cd web
npx vercel       # first run links the project
npx vercel --prod
```
