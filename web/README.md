# Language Drift — web

Interactive visualization of per-year Word2Vec embeddings (TWEC/compass) trained
on Common Crawl 2014–2025. Data is served from Vercel Blob.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · D3.

## Routes

- `/` — scrollytelling landing featuring "Drift Stories" (AI slop, crypto, etc.)
- `/explore` — 3D constellation explorer with search + year scrubbing. Accepts `?w=word` deep links.
- `/space` — joint 2D UMAP "galaxy" with interactive axes and movement heatmaps.
- `/llm` — frequency distribution ridgeline plot (the "frequency fan").
- `/ternary` — three-pole barycentric projection comparison.
- `/arith` — vector arithmetic over the latest-year embeddings.
- `/gallery` — rankings of the top drifters by frequency tier.
- `/w/[word]` — individual word dossier pages.

## Data

Hosted on **Vercel Blob** (not in git), under a versioned path (`data/v4/`); the
base URL lives in `lib/data-source.ts` (overridable via `NEXT_PUBLIC_DATA_BASE`).
Generated by `../scripts/precompute_*.py`, packed by `../scripts/pack_web_data.py`:

- `manifest.json` — search index of all ~52,894 eligible words
- `drift_gallery.json` — pre-sorted top drifters
- `llm.json` — frequency distribution statistics for `/llm`
- `vecs.bin` — all per-word 12×300 float32 vectors, range-fetched (`lib/vectors.ts`)
- `neighbors.bin` + `neighbors_index.json` — neighbor shards packed into one file, range-fetched (`lib/data.ts`)
- `arith.bin`, `space.bin` — whole-file loads for `/arith` and `/space`

Total data size ~450 MB, served from Blob's CDN. To update after a retrain:
re-run precompute scripts + `pack_web_data.py`, upload to a new `data/vN/`,
and bump the version in `lib/data-source.ts`.

## Development

```bash
cd web
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Deploy to Vercel

This is a fully static site (every route prerenders). Recommended setup:

1. Push the repo to GitHub.
2. On vercel.com, "Add new project" → import the repo.
3. Set **Root Directory** to `web`.
4. Deploy.
